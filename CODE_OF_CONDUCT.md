# Code of Conduct / 社区行为准则

## English

KeyPilot contributors and maintainers are expected to communicate respectfully, focus on technical facts, accept constructive feedback, and avoid harassment, discrimination, threats, or disclosure of private information.

Unacceptable behavior may result in comments being removed, participation being limited, or contributors being blocked from project spaces. Report conduct concerns privately through the repository security reporting channel when public discussion would expose sensitive information.

## 简体中文

KeyPilot 的贡献者和维护者应保持尊重，以技术事实为基础沟通，接受建设性反馈，并避免骚扰、歧视、威胁或披露他人隐私。

不当行为可能导致评论被删除、参与权限受限或被禁止进入项目社区。如果公开讨论会暴露敏感信息，请通过仓库安全报告渠道私下反馈行为问题。
